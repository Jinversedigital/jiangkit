media img

Free

Batch images: social sizes, watermark, EXIF strip, convert, find dupes

Installpip install jiangkit (base install)

CLI examplejiang media img fit coffee.jpg -p ig-portrait -o img_fit/ && jiang media img watermark img_fit/coffee.jpg --text '© 匠具 JiangKit' --opacity 0.7

media video

Free

ffmpeg video: trim, concat, 9:16, frames, GIF, subtitles, auto-subs

Installpip install "jiangkit[video]"

CLI examplejiang media video vertical clip.mp4 --size 540x960 -o vertical.mp4

media beat_reels

Pro
