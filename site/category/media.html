media img

免費

批次圖片：IG/Reels/X 尺寸、浮水印、去 EXIF、轉檔、找重複

安裝pip install "git+https://github.com/Jinversedigital/jiangkit" (基本安裝)

指令範例jiang media img fit coffee.jpg -p ig-portrait -o img_fit/ && jiang media img watermark img_fit/coffee.jpg --text '© 匠具 JiangKit' --opacity 0.7

media video

免費

ffmpeg 影片：剪輯、合併、9:16、抽幀、GIF、字幕、自動字幕

安裝pip install "jiangkit[video] @ git+https://github.com/Jinversedigital/jiangkit"

指令範例jiang media video vertical clip.mp4 --size 540x960 -o vertical.mp4
