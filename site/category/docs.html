docs doc

免費

PDF 合併/分割/旋轉/壓縮/轉圖/OCR、Markdown/DOCX 轉 PDF（AGPL 隔離模組）

PyMuPDF 為 AGPL，已隔離於免費模組、不隨附。

安裝pip install "jiangkit[docs] @ git+https://github.com/Jinversedigital/jiangkit"

$ jiang docs doc from-images coffee.jpg astro.jpg -o album.pdf
Combined 2 images -> album.pdf
$ jiang docs doc split album.pdf --outdir pages/
Split into 2 files in pages
$ ls pages/
album_p001.pdf
album_p002.pdf
